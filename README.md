# ピアノれんしゅう記録

家族それぞれが毎日どれだけピアノを練習したかを記録する Web アプリです。
iPad の Safari で開いておくと、マイクでピアノの音を聞いて練習時間を計り、
ピアノの音がしばらく聞こえなくなると自動で終わります。

## 使い方

1. 練習する人の名前をタップして選ぶ（連弾のときは全員）
2. 「れんしゅうスタート」を押す。最初の 1回だけマイクの許可を求められます
3. 練習が終わったら「れんしゅう終了」。押し忘れても、ピアノの音が設定の時間
   （3/5/10/15分）聞こえなければ自動で終わります
4. 記録されるのは、最初にピアノが鳴った 5秒前から、最後に鳴った 10秒後までです。
   スタートを押してから準備していた時間や、終わったあとのおしゃべりは入りません

ホーム画面には、今日の練習時間（秒まで）と今日の目標（名前のまわりの輪）、連続練習日数、
今週（月曜〜日曜）のグラフと合計、今月の合計、最近の記録が出ます。アプリを使わずに練習した日は
「きろく」→「手で追加」で入れられます。

## 目標と、週の注意

- 目標は人ごとに「平日」と「休日・祝日」の 2つです（はじめは全員 20分／45分。設定で変えられます）。
  土曜・日曜と祝日（振替休日・国民の休日を含む）が休日です。祝日は法律の決まりから計算しています
- できない日もあるので、1週間（月曜〜日曜）の合計で見ます。**きのうまでの目標の合計**に今週の練習が
  届いていない人がいると、ホーム画面の上に「あと ○分 足りません」と出ます。今日の分は、今日が
  終わるまで足りない数に入りません
- 月曜日には、先週の合計が目標に届かなかった人を知らせます
- アプリを使いはじめた日より前の日は、目標に数えません

## 楽譜（練習プレーヤー）

上の「楽譜」タブで、練習プレーヤー（1・2・3 発表会アレンジ、エリーゼのために、ガラスのくつ、
ハッピーバースデー 3人連弾）が開きます。曲の切りかえ、テンポ、区間くり返し、段ごとの音量、
メトロノームなどの使い方は、Claude アプリの練習プレーヤーと同じです。

- 楽譜のデータは、家族だけの**合言葉**で暗号化して置いてあります。合言葉は端末ごとに最初の 1回だけ
  入れれば、次からは聞かれません（設定 →「楽譜の合言葉」でも入れられます）
- 練習中に楽譜の音（ピアノやメトロノーム）を鳴らしているあいだは、マイクを止めて、その時間を
  練習として数えます。止めるとマイクがまた聞き始めます（iPad は録音中だと再生の音が小さくなるため）
- 練習中に「楽譜」タブを見ているときは、上に「れんしゅう中 12:34」と出ます。押すと記録の画面に戻ります

## 設定用リンク

設定 →「設定用リンク」の「リンクをコピー」で、合言葉と記録の保存先（接続コード）が入ったリンクを作れます。
LINE やメモに残しておけば、新しい端末や、Safari のデータが消えたときも、タップするだけで元に戻ります。
（Safari は 7日以上開かなかったサイトの保存内容を消すことがあります。）
リンクに入れた合言葉と保存先は、開いたあとアドレス欄から消えます。家族以外には教えないでください。

## iPad での準備

- Safari でこのページを開き、共有ボタン →「ブックマークを追加」か「ホーム画面に追加」
- Safari の設定 →「Web サイト」→「マイク」で、このサイトを「許可」にしておくと、
  毎回の確認がなくなります
- 練習プレーヤー（Claude アプリ）と一緒に使うときは、画面を 2分割して両方を表示します。
  記録アプリの画面が隠れているあいだはマイクが止まります
- 計測中は画面が消えないようにしています。消えてしまうときは
  設定 →「画面表示と明るさ」→「自動ロック」を長めにしてください

## 記録の保存先（GitHub の非公開リポジトリ）

設定しなくても使えますが、その場合は記録がその端末の中だけに残ります。
保存先につなげると、どの端末からでも記録を見られ、「習慣きろく」のピアノの欄にも練習時間が自動で入ります。

記録は、習慣きろくと同じ非公開のデータ用リポジトリ（`Routine-data`）に置きます。つなげるには、
習慣きろくと**同じ接続コード**（`KIROKU1:…`）を使います。

1. 習慣きろくの 設定 →「記録の保存先」→「接続コードをコピー」
   （接続コードの作り方は、習慣きろくの README にあります）
2. コピーした接続コードを LINE やメールで自分に送り、このアプリの 設定 →「記録の保存先」に貼り付ける
3. 「つながるか確かめる」で「つながりました」と出たら、とじる。それまでの記録もまとめて送ります

`piano/records-<年>.json` に 1回の練習が 1行で入ります（日付・開始・終了・分・秒・だれ・終わり方）。
名前と目標の設定は `piano/settings.json` に保存されるので、端末を替えても引き継げます。
端末で GitHub にログインする必要はありません。接続コードはパスワードと同じなので、家族以外には教えないでください。
「保存先につながりません（接続コードの期限切れかもしれません）」と出たら、新しい接続コードを貼り直してください
（記録は端末に残っていて、つながったら送ります）。

## ピアノの音の聞き分け

`detector.js` が 0.01秒ごとに音を調べ、音が鳴り始めた瞬間ごとに次の 4点を確かめます。

- 音の立ち上がりが急か（鍵盤を押した瞬間）
- はっきりした音程（倍音のピーク）があるか
- その音程が 0.05〜0.13秒のあいだ動かないか（話し声は高さが動く）
- あとから大きくならないか（ピアノの音は減っていくだけ）

これを全部満たす音がピアノの音です。C6 より高い音は 4 kHz までに倍音が 1本しかなく、
そばに打鍵の「コツン」という雑音のピークが出てすぐ消えるので、いちばん強い倍音
（1 kHz 以上）が途中で消えずに同じ高さのまま鳴っていれば、それだけでピアノとみなします。

さらに、15秒以内に 2回ピアノの音がしたときだけ
練習中とみなすので、たまたま 1回だけ誤判定しても記録には影響しません。
テスト音（話し声・低くした話し声・手拍子・ノック・雑音）での誤判定は 1分に 0〜1回の単発で、
練習時間には入りません。ピアノは弾いているあいだ数秒おきに検出できています。
ただし C3 より低い音は、倍音どうしが近すぎて判定しにくく、拾えないことがあります
（低音を細かく調べる処理も試しましたが、高音には効果がなかったため外しました）。
テレビやスピーカーから流れるピアノの音楽には反応します。

マイクのテストの一覧には、拾ったすべての音が出ます。ピアノ以外と判定した音には理由が付き、
話し声や物音はたいてい「音の高さがゆれる」になります。これは正しく除外できている印です。

弾いているのに「ピアノの音を待っています」のままになるときや、話し声に反応するときは、
設定の「ピアノの聞き分け」を「ゆるめ」または「きびしめ」にしてください。
設定の「マイクのテスト」で、判定の様子をその場で確かめられます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面（HTML と CSS） |
| `app.js` | 記録・計測・保存の処理 |
| `detector.js` | ピアノの音の聞き分け（ブラウザと Node.js の両方で動く） |
| `calendar.js` | 日本の祝日の計算（休日の目標に使う） |
| `tap-worklet.js` | マイクの音を `detector.js` に渡す AudioWorklet |
| `ghstore.js` | 記録の保存先（GitHub）とのやりとり・接続コード・ファイルの形。習慣きろくと同じ内容 |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |
| `player/index.html` | 練習プレーヤー（Claude アプリ版と同じ本体） |
| `player/songpack.js` | 合言葉で暗号化した曲のデータを読み出す部分 |
| `player/packs/*.bin` | 曲のデータ（楽譜の画像と音符）。AES-GCM で暗号化（鍵は合言葉から PBKDF2 で作る） |
| `player/audio/*.mp4` | ピアノの音（Salamander Grand Piano V3、Alexander Holm、CC BY 3.0）と音色（MuseScore MS Basic、MIT） |

マイクの音は端末の中で調べるだけで、録音もしませんし、どこにも送りません。
送るのは練習の記録（日付・時刻・分・名前）と設定だけで、送り先は自分の非公開リポジトリです。
