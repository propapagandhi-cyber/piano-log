# ピアノれんしゅう記録

家族それぞれが毎日どれだけピアノを練習したかを記録する Web アプリです。
iPad の Safari で開いておくと、マイクでピアノの音を聞いて練習時間を計り、
ピアノの音がしばらく聞こえなくなると自動で終わります。

## 使い方

1. 練習する人の名前をタップして選ぶ（連弾のときは全員）
2. 「れんしゅうスタート」を押す。最初の 1回だけマイクの許可を求められます
3. 練習が終わったら「れんしゅう終了」。押し忘れても、ピアノの音が設定の時間
   （3/5/10/15分）聞こえなければ自動で終わります
4. 記録されるのは、最初にピアノが鳴った 5秒前から、最後に鳴った 10秒後までです。
   スタートを押してから準備していた時間や、終わったあとのおしゃべりは入りません

ホーム画面には、今日の練習時間と 1日の目標（名前のまわりの輪）、連続練習日数、
この 1週間のグラフ、今月の合計、最近の記録が出ます。アプリを使わずに練習した日は
「きろく」→「手で追加」で入れられます。

## iPad での準備

- Safari でこのページを開き、共有ボタン →「ブックマークを追加」か「ホーム画面に追加」
- Safari の設定 →「Web サイト」→「マイク」で、このサイトを「許可」にしておくと、
  毎回の確認がなくなります
- 練習プレーヤー（Claude アプリ）と一緒に使うときは、画面を 2分割して両方を表示します。
  記録アプリの画面が隠れているあいだはマイクが止まります
- 計測中は画面が消えないようにしています。消えてしまうときは
  設定 →「画面表示と明るさ」→「自動ロック」を長めにしてください

## 記録の保存先（Google スプレッドシート）

設定しなくても使えますが、その場合は記録がその端末の中だけに残ります。
スプレッドシートにつなげると、どの端末からでも記録を見られ、表計算で集計もできます。

1. Google ドライブで新しいスプレッドシートを作る
2. 「拡張機能」→「Apps Script」を開き、最初のコードを消して
   [`apps-script.gs`](apps-script.gs) の中身を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、
   「次のユーザーとして実行：自分」「アクセスできるユーザー：全員」で「デプロイ」
4. Google の確認画面で自分のアカウントを選んで許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「移動」）
5. 表示された「ウェブアプリの URL」（…/exec）を、アプリの 設定 →「記録の保存先」に貼り付ける

シート「記録」に 1回の練習が 1行で入ります（日付・開始・終了・分・だれ・終わり方）。
名前と目標の設定もスプレッドシート側に保存されるので、端末を替えても引き継げます。
ウェブアプリの URL を知っている人は記録を読み書きできるので、URL は人に教えないでください。

## ピアノの音の聞き分け

`detector.js` が 0.01秒ごとに音を調べ、音が鳴り始めた瞬間ごとに次の 4点を確かめます。

- 音の立ち上がりが急か（鍵盤を押した瞬間）
- はっきりした音程（倍音のピーク）があるか
- その音程が 0.05〜0.13秒のあいだ動かないか（話し声は高さが動く）
- あとから大きくならないか（ピアノの音は減っていくだけ）

これを全部満たす音がピアノの音です。C6 より高い音は 4 kHz までに倍音が 1本しかなく、
そばに打鍵の「コツン」という雑音のピークが出てすぐ消えるので、いちばん強い倍音
（1 kHz 以上）が途中で消えずに同じ高さのまま鳴っていれば、それだけでピアノとみなします。

さらに、15秒以内に 2回ピアノの音がしたときだけ
練習中とみなすので、たまたま 1回だけ誤判定しても記録には影響しません。
テスト音（話し声・低くした話し声・手拍子・ノック・雑音）での誤判定は 1分に 0〜1回の単発で、
練習時間には入りません。ピアノは弾いているあいだ数秒おきに検出できています。
ただし C3 より低い音は、倍音どうしが近すぎて判定しにくく、拾えないことがあります
（低音を細かく調べる処理も試しましたが、高音には効果がなかったため外しました）。
テレビやスピーカーから流れるピアノの音楽には反応します。

マイクのテストの一覧には、拾ったすべての音が出ます。ピアノ以外と判定した音には理由が付き、
話し声や物音はたいてい「音の高さがゆれる」になります。これは正しく除外できている印です。

弾いているのに「ピアノの音を待っています」のままになるときや、話し声に反応するときは、
設定の「ピアノの聞き分け」を「ゆるめ」または「きびしめ」にしてください。
設定の「マイクのテスト」で、判定の様子をその場で確かめられます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面（HTML と CSS） |
| `app.js` | 記録・計測・保存の処理 |
| `detector.js` | ピアノの音の聞き分け（ブラウザと Node.js の両方で動く） |
| `tap-worklet.js` | マイクの音を `detector.js` に渡す AudioWorklet |
| `apps-script.gs` | Google スプレッドシート側のプログラム |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |

マイクの音は端末の中で調べるだけで、録音もしませんし、どこにも送りません。
送るのは練習の記録（日付・時刻・分・名前）だけです。
